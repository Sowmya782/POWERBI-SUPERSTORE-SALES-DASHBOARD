# Superstore-Sales-Dashboard (Interactive Dashboard creating using Power BI)

---

## PROJECT OBJECTIVES

- Analyze sales and profit performance.
- Monitor key business KPIs.
- Compare sales across regions and categories.
- Identify top-performing products.
- Understand customer and order performance.

---

## Dataset Used

<a href  ="https://github.com/Sowmya782/POWERBI-SUPERSTORE-SALES-DASHBOARD/blob/main/Superstore%20sales%20powerbi%20project.pbix">Sample Superstore Dataset</a> 

---

## Questions (KPIs)

- Compare sales by region

- Compare sales by category and sub-category

- Compare profit across different regions

- Find top-performing products

- Create a chart to display sales over months

- Create a chart to display profit by category

- Analyze sales and profit using different segments

- Identify the contribution of each region to total sales

## Project Insights

- The dashboard analyzes sales, profit, orders, and product data.
- Regional performance can be compared using interactive visuals.
- Category and sub-category performance can be analyzed.
- Monthly sales trends help identify high and low sales periods.
- The dashboard highlights top-performing products and categories.
